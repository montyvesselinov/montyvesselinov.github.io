Estimation of above- and below-ground ecosystem parameters for DVM-DOS-TEM v0.7.0 using MADS v1.7.3

E.E. Jafarov, H. Genet, V.V. Vesselinov, V. Briones, A. Kabeer, A.L. Mullen, B. Maglio, T. Carman, R. Rutter, J. Clein, C.-C. Chang, D. Teber, T. Smith, J.M. Rady, C. Schädel, J.D. Watts, B.M. Rogers, S.M. Natali

Geoscientific Model Development2025DOI: 10.5194/gmd-18-3857-2025

Summary

This study develops an automated parameter calibration method for the DVM-DOS-TEM ecosystem model designed for high-latitude permafrost regions. Using the MADS software package, the authors calibrate rate-limiting parameters controlling carbon and nitrogen dynamics in boreal forests, demonstrating that hierarchical sequential calibration can effectively recover known parameter values even when initial guesses are perturbed by substantial margins.
