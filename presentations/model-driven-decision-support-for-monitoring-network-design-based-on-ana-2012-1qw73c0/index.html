Model-driven decision support for monitoring network design based on analysis of data and model uncertainties: methods and applications

V.V. Vesselinov, D. Harp, D. Katzman

AGU Fall meeting (invited)2012DOI: 10.13140/RG.2.2.17125.04321

Summary

This presentation covers model-driven decision support for monitoring network design based on analysis of data and model uncertainties. It discusses the development and application of methods to evaluate and optimize monitoring strategies under uncertainty. The presentation includes case studies and examples to illustrate the effectiveness of this approach.
