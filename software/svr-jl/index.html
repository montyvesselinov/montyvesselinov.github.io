SVR.jl

Data Analytics • 2019 • Active

SVR.jl provides support vector regression utilities used in model analysis and data-driven prediction workflows.

SVR.jl provides support vector regression capabilities for data-driven regression analysis and predictive modeling workflows.

It fits naturally within the broader MADS and scientific data analytics ecosystem for surrogate modeling and structured regression tasks.

The package offers a lightweight Julia-based option for teams needing interpretable regression utilities alongside other analytical workflows.

Capabilities

  • Support vector regression for predictive modeling
  • Useful for surrogate modeling and data-driven analysis
  • Lightweight Julia package for regression workflows
