MADS

Model Diagnostics • 2010 • Active

MADS is an open-source high-performance framework for model inversion, uncertainty quantification, sensitivity analysis, and decision support across environmental and geoscience applications.

MADS, or Model Analysis and Decision Support, is an integrated open-source high-performance computational framework for data and model analysis.

It has been tested on multi-processor clusters and cloud environments and provides adaptive workflows that reduce manual setup for complex analyses.

MADS can couple to external simulators through template and instruction files and also includes built-in analytical groundwater and contaminant-transport simulators.

The framework has been used for environmental site characterization, source identification, uncertainty quantification, model calibration, and monitoring optimization.

Capabilities

  • Sensitivity analysis, parameter estimation, inversion, and calibration
  • Uncertainty quantification, model selection, and surrogate modeling
  • Machine learning, blind source separation, and decision analysis
